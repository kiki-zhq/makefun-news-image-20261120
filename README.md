The World in One Day — Friday, 20 November 2026. A newspaper front page
that sums up the day's world news in one 1024x1024 image: the Shenzhen
summit's joint "peace declaration" from Trump, Xi and Putin — and, hours
later, Russia's biggest missile attack of the year on Kyiv; the world
court's genocide ruling against Myanmar; markets sliding into correction;
a missile hitting Riyadh's PIF Tower; and new EU–UK deals in Brussels.

`render.py` draws the front page (Pillow, DejaVu fonts) into `entry.png`.
`main.py` is the submitted program: standard library only, it copies
`entry.png` to the output path, so both graded runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
